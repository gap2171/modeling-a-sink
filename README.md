# Modeling a Sink

An interactive sink model built with HTML, CSS, and JavaScript.

The hot knob is on the left and the cold knob is on the right. Each knob goes from 0 to 5. Turn a knob by dragging around it, or use the arrow keys after selecting it. Turning both knobs to 0 stops the water.

The knob settings control flow. Their total sets the width of the stream, and the balance of hot and cold water sets its color and temperature label. The model uses cold, warm, and hot categories rather than actual degrees.

To try it, download the files and open index.html in a browser. Keep style.css and script.js in the same folder.
